# 在vs code的状态栏里批折子

## 支持了洋柿子离线折子 感谢 [zhongbai2333](https://github.com/zhongbai2333/Tomato-Novel-Downloader)  
    地址栏支持输入txt格式的路径。使用大佬的下载器下载txt后食用洋柿子（默认是epub,记得改成txt）

## 重大更新
    某些臣子递来的折子长篇大论不说重点且标题滥竽充数,直接滤过又恐失关键。
    故一键导出当前章回并丢内阁(vscode chat里的AI)先行批阅拟条子。
    比如丢给内阁并吩咐“这章在说什么（一两百字概括），用章回体标题怎么改(只要一个，不需要给理由) ”

#### 目前支持的操作
| 命令 | 描述 | 快捷键 |
|:----:|:----:|:----:|
|Open Bookshelf|展示所有折子名称|
|Delete Book|扔一个折子|
|Start Reading zouzhe|开始读折子|
|Stop Reading zouzhe|停止读折子|
|Add Current Chapter to Chat|把折子丢给AI|ctrl+alt+i|
| |下一页|点击折子左边">" 或者 ctrl+alt+pagedown|
| |上一页|ctrl+alt+pageup|
| |下一段| 点击折子内容 或者 ctrl+alt+end|
| |上一段| ctrl+alt+home|
